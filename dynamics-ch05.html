動量與衝量

衝量動量定理在涉及時間與力的關係時特別有效。從基本定義到線動量守恆，再到碰撞問題與恢復係數的應用，展示動量守恆在各類問題中的強大威力。

8道範例

5.1 衝量、動量與質心

線動量定義

物體的動量定義為質量與速度的乘積：

線動量 p = mv

動量是向量，方向與速度相同，單位為 kg·m/s 或 N·s。

衝量定義

衝量定義為力在作用時間內的效果：

衝量 I = F·Δt = ∫F dt

衝量也是向量，單位與動量相同。衝量動量定理指出，合力的衝量等於動量的變化：

衝量動量定理 I = Δp
F·Δt = m(v₂ - v₁)

質心的概念

多個質點組成的系統中，質心的位置定義為：

質心位置 xc = (m₁x₁ + m₂x₂ + ...) / (m₁ + m₂ + ...)
vc = (m₁v₁ + m₂v₂ + ...) / (m₁ + m₂ + ...)

質心速度等於系統總動量除以總質量。

5.2 線動量守恆與碰撞

線動量守恆定律

當系統不受外力（或外力平衡）時，系統的總動量保持不變：

線動量守恆 p初 = p末
m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'

這個定律在碰撞、爆炸等問題中非常有用。

正向碰撞（一維碰撞）

兩物體沿著同一直線碰撞。除了動量守恆外，還需要用恢復係數來描述碰撞的性質：

恢復係數 e = (v₂' - v₁') / (v₁ - v₂)
或 e = 相對分離速度 / 相對接近速度

e = 0 表示完全非彈性碰撞（兩物體碰撞後黏在一起）；e = 1 表示完全彈性碰撞（動能守恆）；0 < e < 1 表示部分彈性碰撞。

斜向碰撞

當碰撞不沿著運動方向時，將速度分解為法線方向（沿碰撞方向）與切線方向。動量守恆和恢復係數只在法線方向應用，切線方向不受影響。

5.3 角動量

角動量定義

以某一固定點 O 為參考，質點的角動量定義為：

角動量 LO = r × p = r × (mv)
大小：LO = mrv sin θ

其中 r 是質點相對 O 點的位置向量，θ 是 r 與 v 的夾角。對於圓周運動，角動量 L = mrv = mr²ω。

角動量守恆

當合力相對於某一點的力矩為零時，該點的角動量守恆：

角動量守恆條件 τ = 0 ⟹ L = 常數
(r × F) = 0 ⟹ r × (mv) = 常數

典型例子包括行星在太陽周圍的軌道運動（中心力）以及冰上旋轉的人收緊雙臂加快轉速的現象。

範例 5.1：完全非彈性碰撞

質量 2 kg 的小球以 10 m/s 的速度沿著水平面滑行，與靜止的質量 3 kg 的小球正面相碰，兩球碰撞後粘在一起。計算：

  1. 碰撞後兩球的共同速度
  2. 碰撞中損失的動能
解

設 m₁ = 2 kg，v₁ = 10 m/s，m₂ = 3 kg，v₂ = 0（靜止）。

（1）碰撞後的共同速度：

應用動量守恆：m₁v₁ + m₂v₂ = (m₁ + m₂)v'

2 × 10 + 3 × 0 = (2 + 3) × v'

20 = 5v'

v' = 4 m/s

（2）損失的動能：

碰撞前的動能：T₁ = ½ × 2 × 10² = 100 J

碰撞後的動能：T₂ = ½ × 5 × 4² = 40 J

損失的動能：ΔT = 100 - 40 = 60 J

這 60 J 轉化為形變、熱量和聲音等，不再是機械能。

範例 5.2：有恢復係數的碰撞

質量 1.5 kg 的球 A 以 8 m/s 速度沿著光滑水平面滑動，迎面碰撞靜止的質量 2.5 kg 的球 B。碰撞的恢復係數 e = 0.6。計算碰撞後兩球的速度。

解

設 mA = 1.5 kg，vA = 8 m/s，mB = 2.5 kg，vB = 0，e = 0.6。

列出兩個方程：

動量守恆：1.5 × 8 + 2.5 × 0 = 1.5 × v'A + 2.5 × v'B

12 = 1.5v'A + 2.5v'B ... (1)

恢復係數：e = (v'B - v'A) / (vA - vB)

0.6 = (v'B - v'A) / 8

v'B - v'A = 4.8 ... (2)

求解：

由 (2)：v'B = v'A + 4.8

代入 (1)：12 = 1.5v'A + 2.5(v'A + 4.8)

12 = 1.5v'A + 2.5v'A + 12

0 = 4v'A

v'A = 0 m/s

v'B = 0 + 4.8 = 4.8 m/s

碰撞後，球 A 靜止，球 B 以 4.8 m/s 運動。
