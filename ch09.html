9-1概述

依產品用途，對材料施以不同處理以獲得所需的機械性質。可分兩大類：

一般熱處理

控制加熱溫度、保溫時間與冷卻速率，改變材料整體的組織與性質：退火、正常化、淬火、回火，以及恆溫熱處理。用於承受高負荷、傳遞動力的元件，如結構鋼、汽車安全零件。

表面處理

只改變表層的機械或化學性質，得到外硬內韌或耐蝕、隔熱的表面：表層硬化（火焰、感應、滲碳、氮化）與表面披覆（PVD、CVD）。用於齒輪、凸輪、耐磨鋼板、刀具塗層等。

9-2一般熱處理

一、退火

將鋼加熱到適當溫度、保溫後緩慢冷卻（通常爐冷）。依目的與加熱溫度分為多種：

種類目的加熱溫度與操作重點
均質化退火
擴散退火		消除鑄造、熱加工或銲接造成的偏析，使成分均勻大鋼錠 1200–1300 °C；高碳鋼、加工半成品 1100–1200 °C；保溫數小時至數十小時後緩冷晶粒會粗大，之後須再完全退火或正常化細化；用於高價合金、偏析嚴重的鋼錠
完全退火
相變退火		軟化，改善切削性與塑性，細化並調整組織亞共析鋼 A₃ + 30–50 °C，過共析鋼 A₁ + 30–50 °C；沃斯田化後爐冷亞共析鋼得肥粒鐵 + 粗波來鐵。適合中碳鋼；低碳鋼退火後太軟黏刀，宜正常化；過共析鋼易沿晶界析出網狀雪明碳鐵而變脆，宜球化退火
球化退火把層狀雪明碳鐵變成約 0.5–1.5 µm 的球狀碳化物散布在肥粒鐵中例：加熱到 A₁ 稍上（760–780 °C）保溫，爐冷到約 600 °C 後空冷；或 A₁ 稍下長時間保溫、在 A₁ ± 30 °C 反覆加熱冷卻等改善高碳鋼、工具鋼的切削性與冷加工性；作為淬火前處理可提高淬火後韌性、防止淬裂
不完全退火同完全退火，用於亞共析鋼加熱到 A₁ 與 A₃ 之間只有波來鐵部分變成沃斯田鐵再變回，初析肥粒鐵不變；耗能少、脫碳氧化少
再結晶退火
製程退火		消除冷作硬化，恢復延性以便繼續加工A₁ 以下的再結晶溫度範圍保溫無相變態；過程依序為回復 → 再結晶 → 晶粒成長（見第 5 章）。加工度太小的工件不易再結晶，反而晶粒粗大
弛力退火
低溫退火		消除鑄造、銲接、加工後的殘留應力約 450 °C 以上應力開始釋放，常在 500–650 °C 保溫後緩冷無組織變化、最省能；防止日後變形與應力腐蝕
恆溫退火縮短退火時間，得到均勻的波來鐵，改善切削性沃斯田化（約 800–900 °C）後急冷到 TTT 圖鼻部稍上（約 600–700 °C），恆溫到波來變態完成，再空冷在變態最快的溫度附近恆溫，時間比爐冷大幅縮短；用於低合金鋼汽車零件

二、正常化

將鋼加熱到 A₃（亞共析鋼）或 Acm（過共析鋼）以上 30–50 °C，完全沃斯田化後在靜止空氣中冷卻，得到均勻細密的標準組織（細波來鐵）。

目的

細化晶粒、消除過熱或加工造成的粗大不均組織、消除殘留應力；過共析鋼加熱到 Acm 以上可打散網狀雪明碳鐵。

與退火比較

正常化空冷、退火爐冷；正常化組織較細，強度、硬度略高，且出爐冷卻，生產效率高。低碳鋼常以正常化取代退火以改善切削性。

其他形式

二段正常化：先空冷到約 550 °C 再爐冷，減少複雜或斷面變化大零件的變形。恆溫正常化：以氣流冷到約 550 °C 恆溫完成波來變態後空冷。正常化也常作為淬火或球化退火的前處理。

三、淬火

亞共析鋼加熱到 A₃ + 30–50 °C、過共析鋼加熱到 A₁ + 30–50 °C，保溫使組織變為沃斯田鐵（過共析鋼保留部分雪明碳鐵以增耐磨性），再以大於臨界冷卻速率急冷，得到麻田散鐵，提高硬度與強度，但韌性下降。

注意事項

沃斯田鐵變為麻田散鐵時體積膨脹，加上內外溫差產生熱應力，易變形、淬裂；淬火後脆而內應力大，必須回火。含碳量愈高淬火硬度愈高，但超過約 0.6% C 後增加趨緩。

深冷處理

麻田散變態量只與溫度有關；高碳鋼或合金鋼 Mf 低於室溫，淬到室溫仍有殘留沃斯田鐵，日後會緩慢變態造成尺寸變化。繼續冷到 0 °C 以下（如 −80 °C）使其轉為麻田散鐵，稱為深冷（次零）處理，常用於量規與精密零件。

質量效應：工件尺寸愈大，中心冷速愈慢，表面得麻田散鐵而中心得吐粒散鐵等較軟組織，內外硬度不一甚至淬裂。添加 Cr、Mo、Mn、Ni 等合金元素可提高硬化能、減少質量效應。

四、回火

將淬火鋼再加熱到 A₁ 以下適當溫度保溫後冷卻，使麻田散鐵中過飽和的碳析出成碳化物，消除內應力、降低硬度並提高韌性。

種類溫度組織用途
低溫回火150–200 °C回火麻田散鐵消除內應力與脆性，保持高硬度與耐磨性；刀具、量規、軸承、滲碳件
高溫回火500–650 °C回火糙斑鐵（肥粒鐵 + 粒狀雪明碳鐵）強度、韌性、延性兼具。淬火 + 高溫回火 = 調質處理；軸、連桿、螺栓、齒輪

調質 vs. 正常化

兩者都得到細密組織，但調質的雪明碳鐵呈粒狀，正常化呈層片狀；在相同硬度下，調質材的韌性、延性與疲勞強度都較好。

回火脆性

在某些溫度區間回火，韌性反而明顯下降：碳鋼約 250–400 °C（低溫回火脆性）；Cr、Ni、Mn 合金鋼在約 450–550 °C 回火或緩冷通過此區（高溫回火脆性），加 Mo 或回火後急冷可減輕。

五、恆溫熱處理

配合 TTT 圖，在冷卻途中於特定溫度停留，可減少淬裂與變形，或得到變韌鐵。

方法操作組織與特點
麻淬火
marquenching		淬入 Ms 稍上的熱浴，停留到表面與中心溫度一致，再空冷通過 Ms，之後回火麻田散鐵（再回火）；內外同時變態，變形與淬裂大幅減少，工時短，工業上應用最廣
沃斯回火
austempering，恆溫回火		淬入 Ms 以上、鼻部以下的熱浴，恆溫到變韌鐵變態完成後冷卻下變韌鐵；不需回火，強韌性佳、變形小；受限於冷速，只適合小件、薄件
麻回火
Ms–Mf 間恆溫		淬入 Ms 與 Mf 之間的熱浴恆溫：已生成的麻田散鐵自行回火，其餘沃斯田鐵變為下變韌鐵回火麻田散鐵 + 下變韌鐵，硬度與韌性兼具，不需另行回火；但變態時間長、成本高

9-3表面處理

一、表層硬化：物理式（只加熱表面再淬火，成分不變）

（一）火焰硬化

以氧乙炔等高溫火焰迅速加熱工件表層至沃斯田化溫度，緊接著噴水急冷，使表層變成麻田散鐵。適用含碳 0.35–0.55% 的中碳鋼、低合金鉻鉬鋼、鑄鋼與鑄鐵。加熱時間愈長、火焰移動愈慢，硬化層愈深。

方式操作
固定式燃燒器與工件都不動，加熱後整體噴水；適合小面積局部硬化
回轉式工件旋轉、燃燒器固定，周面加熱後一次噴水；適合小直徑軸、齒輪
線形移動式燃燒器與冷卻管一起沿工件直線移動，邊加熱邊冷卻；適合導軌、長平面
回轉移動式工件旋轉，燃燒器與冷卻管沿軸向移動；適合長軸

優點

設備簡單、成本低、效率高；工件大小不受限；可做局部（選擇性）淬火。

缺點

溫度不易精確控制，硬度與硬化深度不均，大件更明顯；易過熱。

（二）感應硬化

線圈通以高頻交流電，在工件表層感應出渦電流，依焦耳熱迅速升溫，隨即噴水淬火。適用含碳 0.4% 以上的碳鋼與合金鋼。電流集中在表面的現象稱集膚效應：頻率愈高，加熱層愈薄——小而薄的工件用高頻，大而厚的工件用較低頻率。

優點

加熱快、溫度易控制、硬化層均勻；氧化脫碳少；表層晶粒細；易納入生產線自動化，效率高。

缺點

設備與線圈成本高，線圈須配合工件形狀設計，複雜形狀不易處理；加熱時間短，碳化物不易完全固溶。

此外也可用雷射、電子束、電漿等高能束加熱表面，熱輸入集中、變形極小，可自冷淬火。

（三）喬米尼硬化能試驗

用來比較不同鋼種的硬化能（淬火時能硬化的深度）。標準試棒 Φ25.4 × 101.6 mm，沃斯田化（如 1018 鋼加熱到 925 °C）後上端懸吊，以自由水柱由下往上噴淬火端約 10 分鐘；冷卻後沿長度磨出平面，每隔固定距離量 HRC。淬火端冷速最快、硬度最高，愈往上愈軟；曲線愈平緩表示硬化能愈好。

二、表層硬化：化學式（改變表層成分）

（一）滲碳法

將低碳鋼（約 0.1–0.25% C）在沃斯田鐵狀態下讓碳原子擴散進入表層，使表層含碳量提高到約 0.8–1.0%，再淬火、低溫回火：表面硬而耐磨，心部仍為低碳而強韌。不需滲碳的部位可鍍銅遮蔽。

方法做法特點
固體滲碳工件埋入滲碳劑（木炭粉約 70% + 碳酸鋇等促進劑約 30%），密封於箱中加熱到 850–950 °C 保溫設備簡單；層深可厚，但加熱慢、深度不易精確控制、勞力多
2C + O₂ → 2CO；BaCO₃ → BaO + CO₂，CO₂ + C → 2CO；3Fe + 2CO → Fe₃C + CO₂
液體滲碳
氰化法		浸入熔融氰化鈉（NaCN）鹽浴；高於約 700 °C 以滲碳為主，較低溫則氮化作用增強，故又稱滲碳氮化加熱均勻快速、層薄（約 0.3–0.8 mm）、表面光潔、變形小；氰鹽劇毒，廢液處理困難
氣體滲碳在爐中通入天然氣、丙烷或 CO 系吸熱型氣體，加熱分解出活性碳
2CO ⇄ C + CO₂；CH₄ → C + 2H₂		碳勢與層深容易精確控制、品質穩定、可連續作業，是目前量產最主要的滲碳法
滲碳後熱處理：滲碳在高溫長時間進行，晶粒粗大。傳統做法為二次淬火：第一次自較高溫（心部 A₃ 以上）淬火細化心部組織；第二次自表層 A₁ 稍上淬火使滲碳層硬化；最後低溫回火（必要時加深冷處理消除殘留沃斯田鐵）。

（二）氮化法

先將含 Al、Cr、Mo 的氮化鋼淬火、回火（調質），再在約 500–550 °C 的氨氣中長時間加熱：2NH₃ → 2N + 3H₂，活性氮擴散入表層與合金元素形成硬的氮化物。Al 主要提高表面硬度，Cr 有助增加氮化層深度。氮化後不需淬火。

軟氮化
Tufftride		以氰酸鹽（KCNO 等）鹽浴為主，吹入空氣分解出活性 N 與少量 C，約 570 °C 短時間處理化合物層僅數 µm 至約 20 µm，但耐磨、耐蝕、抗咬合佳，任何鋼種皆可；適合量大的小零件

三、表層披覆

（一）物理氣相沉積 PVD

在真空中以物理方式使鍍膜材料變成原子、分子或離子，飛到工件表面凝結成薄膜，工件溫度約 200–500 °C。

真空蒸鍍

高真空中以電阻或電子束加熱鍍材使其蒸發，蒸氣直線飛到工件凝結。最簡單普及；真空度愈高膜質愈好，但附著力較弱、有陰影效應。

濺鍍

通入低壓氬氣，鍍材作靶（陰極），加高壓使氬氣輝光放電，Ar⁺ 撞擊靶材把原子濺出，沉積在工件上。可鍍高熔點金屬與合金，成分容易保持，膜緻密均勻。

離子鍍膜

蒸發的鍍材在電漿中離子化，被負偏壓的工件加速吸引而撞擊沉積，附著力最好、繞鍍性佳。刀具 TiN、TiAlN 塗層多用此法。

（二）化學氣相沉積 CVD

將工件置於加熱的反應室，通入含鍍膜元素的反應氣體（如 TiCl₄ + N₂ + H₂），在工件表面發生化學反應而沉積成膜（如 TiN、TiC、Al₂O₃）。

比較PVDCVD
原理物理蒸發、濺射後凝結氣相化學反應生成
處理溫度低，約 200–500 °C高，約 800–1100 °C（電漿輔助 PECVD 可降低）
附著力與繞鍍性直線性，複雜形狀較差附著力好，可均勻鍍覆複雜形狀與孔內
對基材影響小，可用於已淬硬的高速鋼與精密件高溫使淬火鋼軟化、變形，精密件需再熱處理；適合碳化物刀片
環保乾式、無毒反應氣體與副產物常有毒或腐蝕性

02分別說明滲碳法和氮化法的硬化處理過程、硬度分布及硬化深度。關務三等
滲碳：低碳鋼於 850–950 °C 在固體、液體或氣體滲碳劑中使碳擴散入表層，再淬火、低溫回火；硬度由表面約 HRC 60 隨含碳量下降逐漸降至心部，硬化層約 0.5–2 mm。氮化：含 Al、Cr、Mo 的鋼先調質，於 500–550 °C 氨氣中長時間加熱，形成氮化物，不需淬火；表面硬度更高（約 HV 900–1200），但向內陡降，層深約 0.1–0.6 mm。見 9-3 節比較表。
03說明 VLSI 製程中 PVD 及 CVD 兩種薄膜製程及其優缺點。鐵路員級
PVD：真空中以蒸鍍或濺鍍使靶材原子沉積（如鋁、銅導線層、阻障層）；優點為低溫、膜純度高、無毒、可鍍金屬與合金；缺點為階梯覆蓋差、深孔填充不佳。CVD：反應氣體在晶圓表面化學反應成膜（如 SiO₂、Si₃N₄、多晶矽、鎢）；優點為階梯覆蓋與均勻性好、可大量批次、膜成分易調；缺點為溫度較高、氣體有毒、可能有雜質，可用 LPCVD、PECVD 降低溫度。
04詳述珠擊以及滲碳法在表面處理上的重要目的。機械技師
珠擊：以高速鋼珠撞擊表面，使表層塑性變形並產生壓縮殘留應力與加工硬化，抵消外加拉應力，大幅提高疲勞強度並抑制應力腐蝕裂縫，用於彈簧、齒輪、曲軸。滲碳：提高低碳鋼表層含碳量，淬火後表面硬而耐磨、心部保持韌性，承受衝擊與接觸疲勞，用於齒輪、凸輪、活塞銷；淬火後表層亦有壓縮應力，有利疲勞強度。
05說明經嚴重塑性加工的金屬在退火時發生再結晶的原因與過程。地特四等
原因：冷加工使差排密度大增，晶粒內儲存大量應變能，處於不穩定狀態，成為再結晶的驅動力；加工度愈大，再結晶溫度愈低。過程：① 回復——空位與差排重新排列，內應力降低，硬度變化不大；② 再結晶——在應變能高處形成無應變的新晶核並成長取代變形晶粒，強度、硬度下降，延性恢復；③ 晶粒成長——為降低晶界能，晶粒合併長大。
06試述退火、回火及正常化的差異。鐵路員級
退火：加熱到依目的而定的溫度後爐冷，目的為軟化、均質化、消除應力；組織為粗波來鐵或球化碳化物。正常化：加熱到 A₃／Acm 以上 30–50 °C 後空冷，得細波來鐵，細化晶粒、強度略高於退火。回火：淬火後再加熱到 A₁ 以下保溫冷卻，消除淬火應力、調整硬度與韌性；退火與正常化都經沃斯田化，回火則不經相變。
07何謂熱處理？其功能及重要步驟為何？高考三等
熱處理是在固態下控制加熱溫度、保溫時間與冷卻速率，改變金屬組織以得到所需性質的方法。功能：軟化以利加工、硬化強化、提高韌性、消除殘留應力、細化晶粒、均質化、改善切削性與耐磨性。步驟：加熱（控制升溫速率避免熱應力）→ 保溫（使組織均勻變態，如沃斯田化）→ 冷卻（以爐冷、空冷、油冷、水冷決定組織），必要時再回火。
08何謂 CVD 及 PVD？其加工原理為何？高考三等
PVD（物理氣相沉積）：真空中以蒸發、濺射或離子化等物理方式使鍍材成為氣相粒子，直線飛到工件表面凝結成膜，溫度約 200–500 °C。CVD（化學氣相沉積）：反應氣體送入加熱反應室，在工件表面發生化學反應生成固態膜（如 TiCl₄ + ½N₂ + 2H₂ → TiN + 4HCl），溫度約 800–1100 °C。見 9-3 節比較表。
09金屬熱處理如何改變材料性質？關務四等
藉由相變態與擴散改變微觀組織：加熱到 A₁／A₃ 以上形成沃斯田鐵，冷卻速率決定產物——緩冷得粗波來鐵（軟、韌），空冷得細波來鐵，中速得變韌鐵，急冷得麻田散鐵（最硬）；回火使碳化物析出、內應力消除。另外再結晶退火藉晶粒重生消除加工硬化，均質化退火靠擴散消除偏析，時效硬化靠析出物阻擋差排。
10說明火焰硬化熱處理製程及其增加材料表面硬度的機制。關務三等
製程：以氧乙炔等高溫火焰迅速加熱中碳鋼（0.35–0.55% C）或鑄鐵表層到沃斯田化溫度，緊接著噴水急冷；依工件形狀採固定式、回轉式、線形移動式或回轉移動式，之後低溫回火。機制：只有表層被加熱到 A₃ 以上成為沃斯田鐵，急冷時以大於臨界冷卻速率冷卻轉變為麻田散鐵而變硬；心部未達變態溫度，維持原有韌性，形成外硬內韌，且表層體積膨脹產生壓縮殘留應力。
