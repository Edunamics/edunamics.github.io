1-1力學的分類

力學（mechanics）是物理學的一支，研究物體受力後的運動效應，以及物體內部產生的效應。工程上把靜力學、動力學、材料力學合稱為工程力學（或機械力學）。

三門工程力學的分工

科目物體假設研究內容求的是
靜力學剛體（不變形）力作用於靜止物體時，力系的合成與平衡條件合力、支承反力、構件內力
動力學剛體或質點運動學只描述運動（位移、速度、加速度）；力動學再加入造成運動的力速度、加速度與力的關係
材料力學可變形體（彈性體）外力在物體內部產生的應力與變形應力、應變、變形量
為什麼可以把物體當剛體？工程結構受力後的變形，通常只有尺寸的千分之一以下，對力的作用位置與角度幾乎沒有影響，所以求平衡時忽略變形。但遇到「反力比平衡方程式還多」的靜不定問題，就必須借用材料力學的變形條件才能解。

1-2力與向量

凡能使物體改變運動狀態（或靜止狀態），或有此傾向者，稱為力（force）。

一、力的三要素

大小

單位為 N、kN 等。

方向

包含作用線的方位與指向。

作用點

力施加在物體上的位置。

「單位」不是力的要素，這是選擇題常見的陷阱。

二、力的分類

分類依據種類說明與例子
來源外力物體受到外界的作用力，例如負載、支承反力
內力物體內部各部分之間的作用力，必定成對出現、大小相等方向相反
傳遞方式接觸力兩物體接觸才產生，例如摩擦力、繩的拉力、壓力
超距力不必接觸也能作用，例如重力、磁力、電力

三、力的效應

外效應

力使物體的運動狀態改變（移動、轉動），例如投籃、射飛鏢。靜力學、動力學研究的是外效應。

內效應

力使物體變形，並在內部產生應力來抵抗外力。這是材料力學的範圍。

四、純量與向量

定義例子
純量只有大小，用一個數值（可正可負）即可表示質量、長度、時間、溫度、面積、功、能量、功率
向量同時具有大小與方向，相加須依平行四邊形法則位移、速度、加速度、力、力矩、動量、衝量

向量書寫時在字母上加箭號，例如 F；大小寫成 |F| 或直接寫 F。

五、向量依「作用點能否移動」再分三種

種類特徵例子
自由向量只要大小、方向不變，可放在空間任何位置力偶矩、剛體平移時的速度
滑動向量可沿自己的作用線前後移動，不能離開作用線作用於剛體、只看外效應的力
拘束向量作用點固定，不可移動產生內效應（變形）的力

六、質點、剛體與力的可傳性

質點

把物體的質量視為集中於一點，只考慮移動、不考慮轉動。

剛體

受力後形狀與大小都不改變，也就是體內任兩點的距離永遠不變。剛體是理想化模型，真實世界並不存在。

力的可傳性：作用於剛體的力，在大小與方向不變的情況下，可沿其作用線移到任何一點，外效應不變。

可傳性只對「剛體的外效應」成立。上圖兩種情形塊體的加速度相同，但前者塊體受壓、後者受拉，內效應完全不同。另外，力只能沿作用線滑動；若移到平行的另一條線上，必須補上一個力偶（見 1-5）。

1-4力的分解與合成

把一個力換成數個等效分力，稱為力的分解；把一組力換成一個不改變外效應的單力，稱為力的合成，該單力即合力 R。

作用力、負載合力、反力、力矩尺寸、座標

一、單力分解為兩垂直分力

一力可分解成無限多組分力。計算上最方便的是沿互相垂直的 x、y 軸分解：

直角分量
F = Fx i + Fy j = F cos θ i + F sin θ j
F = √(Fx² + Fy²)　　θ = tan⁻¹(Fy / Fx)

分力不一定比合力小。沿兩條不垂直的軸分解時，分力可以大於、等於或小於合力（計算題 7 就是一例）。

二、多力合成

1. 作圖法（力多邊形）：將各力依比例首尾相接，從第一力的起點連到最後一力的終點，就是合力 R，可直接量出大小與方向。力的相加順序不影響結果。

2. 代數法（分量法）：先把每個力分解，再分別加總。

代數法
ΣFx = F1 cos θ1 + F2 cos θ2 + …　　ΣFy = F1 sin θ1 + F2 sin θ2 + …
R = √((ΣFx)² + (ΣFy)²)　　α = tan⁻¹(ΣFy / ΣFx)
方向角要看象限。tan⁻¹ 只會給出 −90°～90° 的值。先由 ΣFx、ΣFy 的正負判斷合力落在哪一象限，再寫出方向，例如「與 −x 軸夾 58.2°，指向左上」。

三、兩力合成：平行四邊形法

餘弦定律求大小
R = √(P² + Q² + 2PQ cos α)
tan θ = Q sin α / (P + Q cos α)
正弦定律求方向
Q / sin θ = R / sin(180° − α) = R / sin α
正負號別記反。三角形餘弦定律是 c² = a² + b² − 2ab cos C，其中 C 是三角形的內角；合力公式用的是兩力的夾角 α，兩者互補（180° − α），所以變成「＋」號。

1-5力矩與力偶

一、力矩

力除了讓物體移動，也可能讓物體繞某點（或某軸）轉動。這種轉動傾向稱為力矩（moment），大小等於力乘以力臂。

力矩
MO = F · d
向量形式：MO = r × F　平面上：MO = x Fy − y Fx（逆時針為正）
單位：N·m、kN·m、kgf·m

向量形式中 r 是從力矩中心 O 指向作用線上任一點的位置向量。外積順序是 r × F，不能寫成 F × r。

二、力矩原理（Varignon 定理）

一力系的合力對某點的力矩，等於各分力對同一點力矩的代數和。實務上常把斜向力拆成水平、垂直兩分量，各乘各自的力臂再相加，比找垂直距離快。

三、力矩的特性

平行

力的作用線與力矩軸平行，對該軸力矩為零。

相交

作用線（或其延長線）通過力矩中心，力臂為零，力矩為零。

可傳

力沿作用線移動，力臂不變，力矩不變。

四、力偶

兩力大小相等、方向相反、作用線平行但不重合，稱為力偶（couple）。力偶的合力為零，只產生轉動效應。

對任何點都一樣

力偶對空間任一點的力矩都等於 F·d，與力矩中心的位置無關，因此力偶矩是自由向量。

三要素

力偶矩的大小、轉向（順或逆時針）、作用面的方位。

等值力偶

只要 F·d 與轉向相同，可任意改變 F 與 d 的組合，或在同一平面（及平行平面）內移動。

無法用單力平衡

力偶的合力為零，只能用另一個大小相等、轉向相反的力偶來平衡。

五、力與力偶的互換

作用於 A 點的力 F，可以等效換成：作用於任一點 O 的同一個力 F，再加上一個力偶 C = F·d（d 為 O 到原作用線的垂直距離）。反過來，一個力加一個同平面的力偶，也能合成為一個平移後的單力。

等值力系的判斷：兩組力系若合力相同，且對同一點的合力矩相同，即為等值力系，對剛體產生相同的外效應（見範例 7）。

1-6分布負載與支承

分布在梁上的負載，求反力時可換成一個等效集中力：大小等於負載圖的面積，作用在負載圖的形心。

作用力、負載合力、反力、力矩尺寸、座標

一、常見支承與反力

鉸支承（銷）

限制移動、不限轉動。兩個反力 Rx、Ry。

滾支承

只限制垂直支承面的移動。一個反力，方向垂直支承面。

固定端

移動與轉動都被限制。Rx、Ry 與反力矩 M 共三個。

範例 1

吊環受 20 kN、30 kN、42 kN 三力，方向如圖。(1)～(3) 求各力的 x、y 分量；(4) 求 20 kN 與 30 kN 的合力；(5) 求三力的合力。

解答

先換成與 +x 軸的夾角：20 kN 為 40°，30 kN 為 180° − 20° − 50° = 110°，42 kN 為 160°。

(1) 20 kN：Fx = 20 cos 40° = 15.32 kN，Fy = 20 sin 40° = 12.86 kN
(2) 30 kN：Fx = −30 cos 70° = −10.26 kN，Fy = 30 sin 70° = 28.19 kN
(3) 42 kN：Fx = −42 cos 20° = −39.47 kN，Fy = 42 sin 20° = 14.36 kN
(4) ΣFx = 15.32 − 10.26 = 5.06，ΣFy = 12.86 + 28.19 = 41.05
R = √(5.06² + 41.05²) = 41.36 kN，θ = tan⁻¹(41.05 / 5.06) = 82.97°（與 +x 軸）
另解（兩力夾 70°）：R = √(20² + 30² + 2·20·30·cos 70°) = 41.36 kN
(5) ΣFx = −34.41，ΣFy = 55.41 → R = 65.22 kN，在第二象限，與 −x 軸夾 58.2°（即與 +x 軸 121.8°）

範例 396 年台電

懸臂梁固定於 A（梁頂），梁深 1 m。兩個 100 kN 斜向力（斜率 3：4）如圖，求兩力對 A 點的力矩：(A) 240　(B) 480　(C) 720　(D) 780 kN·m

解答

每個力拆成水平 60 kN（向左）與垂直 80 kN（向下）。以 A 為原點，順時針為負：

中間的力作用在梁頂（與 A 同高）：水平分量力臂為 0，M = −80 × 3 = −240 kN·m
端點的力作用在梁底：M = −80 × 6 − 60 × 1 = −540 kN·m
ΣMA = −780 kN·m，即 780 kN·m 順時針，選 (D)。
範例 497 年台電

A 端為固定端，力 P 作用於 B 點，與水平夾 θ 角向右下。θ 為多少時，P 對 A 點的力矩最大？(A) 0°　(B) 30°　(C) 45°　(D) 90°

解答

B 相對 A 的位置為 (4, 4) m。P 拆成水平 P cos θ（向右）與垂直 P sin θ（向下），兩者對 A 都是順時針：

M = P cos θ × 4 + P sin θ × 4 = 4P(cos θ + sin θ)
dM/dθ = 4P(−sin θ + cos θ) = 0 → tan θ = 1 → θ = 45°，選 (C)。

此時 Mmax = 4√2 P。也可以直接看：力矩最大時，力要垂直於 AB 連線，而 AB 與水平夾 45°。

簡支梁受 8 kN 集中力與 4 kN/m 均佈負載，求 A 點反力。

解答

均佈負載換成 4 × 3 = 12 kN，作用在其中點，距 B 1.5 m。對 B 取力矩：

ΣMB = 0：RA × 6 = 8 × 4.5 + 12 × 1.5 = 54
RA = 9 kN（↑）
範例 6108 年台電

C 點受順時針力偶 M = 5 kN·m，CB 段受 q = 5 kN/m 均佈負載，B 端為置於 30° 斜面上的滾支。A 點支承反力大小最接近：(A) 4.37　(B) 5.23　(C) 6.14　(D) 7.53 kN

解答

滾支反力 RB 垂直斜面，與鉛垂線夾 30°，指向左上。均佈負載合力 15 kN，距 B 1.5 m。

ΣMB = 0：Ay × 4 + 5 = 15 × 1.5 → Ay = 4.375 kN（↑）
ΣFy = 0：4.375 + RB cos 30° = 15 → RB = 12.27 kN
ΣFx = 0：Ax = RB sin 30° = 6.13 kN（→）
RA = √(6.13² + 4.375²) = 7.53 kN，選 (D)。

斜面上的滾支會產生水平分力，A 點因此也有水平反力。若把 RB 當成鉛直，就會誤選 (A)。

範例 797 年台電

下列四組力系中，哪兩組互為等值力系？（梁長皆為 4 m）

解答

逐一算合力，以及對左端的合力矩（逆時針為正）：

力系合力對左端合力矩
(a)600 N ↓−200×4 + 200 − 600 = −1200 N·m
(b)600 N ↓−300×4 + 2400 − 300 = +900 N·m
(c)900 − 300 = 600 N ↓−900×4 + 4500 = +900 N·m
(d)600 N ↓−400×4 − 600 + 200 = −2000 N·m

(b)、(c) 的合力與合力矩都相同，互為等值力系。四組的合力都是 600 N，所以只比合力不夠，一定要再比力矩。

計算計算題演練

計算 1

P = 40 N、Q = 60 N 共同作用於螺栓，P 與 x 軸夾 30°，Q 與 P 再夾 30°。求 x、y 方向的合力。

解答
ΣFx = 60 cos 60° + 40 cos 30° = 30 + 34.64 = 64.64 N
ΣFy = 60 sin 60° + 40 sin 30° = 51.96 + 20 = 71.96 N
R = √(64.64² + 71.96²) = 96.7 N，與 x 軸夾 48.1°
計算 2

求三力的合力大小，以及合力與水平的夾角。

解答
ΣFx = 250 × 4/5 − 200 cos 60° = 200 − 100 = 100 N
ΣFy = 250 × 3/5 + 200 sin 60° − 150 = 150 + 173.2 − 150 = 100√3 N
R = √(100² + (100√3)²) = 200 N
tan α = ΣFy / ΣFx = √3 → α = 60°，指向右上
計算 3

F1 = 600 N、F2 = 400 N 作用於吊環，求合力大小與方向。

解答
ΣFx = 600 cos 30° − 400 sin 45° = 519.6 − 282.8 = 236.8 N
ΣFy = 600 sin 30° + 400 cos 45° = 300 + 282.8 = 582.8 N
R = √(236.8² + 582.8²) = 629.1 N
θ = tan⁻¹(582.8 / 236.8) = 67.9°（與 +x 軸）
計算 4

求 200 N 的力對 A 點產生的力矩。

解答

B 相對 A 的位置：x = 0.2 m、y = 0.1 m。力的分量 Fx = Fy = 200 sin 45° = 141.4 N。

MA = x Fy − y Fx = 0.2 × 141.4 − 0.1 × 141.4 = 14.1 N·m（逆時針）

垂直分量讓桿件逆時針轉，水平分量讓它順時針轉，兩者要相減。

計算 5

B、C 兩點受一對 60 N 的力偶。將此力偶分別換成作用在 A、B 的水平力偶，以及作用在 C、D 的水平力偶。

解答
原力偶：C = 60 × 18 = 1080 N·cm（逆時針）
A、B 間距 24 cm：FAB = 1080 / 24 = 45 N
C、D 間距 12 cm：FCD = 1080 / 12 = 90 N

兩組水平力的轉向都要維持逆時針：A 點的力向左、B 點的力向右；D 點的力向左、C 點的力向右。

計算 6

簡支梁受 20 N/m 均佈負載，右段 3 m 再疊加一個由 0 增至 20 N/m 的三角形負載。以一個等值合力取代，並求其距 A 點的位置。

解答
矩形：20 × 5 = 100 N，距 A 2.5 m
三角形：½ × 20 × 3 = 30 N，距 A 2 + 3 × 2/3 = 4 m
R = 130 N；130 x = 100 × 2.5 + 30 × 4 = 370 → x = 2.85 m
計算 7

F = 141.5 N 作用於固定托架，與 x 軸夾 15°；x' 軸在 x 軸下方 30°，y' ⊥ x'。將 F 分解為：(1) x、y 分量；(2) x'、y' 分量；(3) 沿 x' 與 y 兩軸的分量。

解答
(1) Fx = 141.5 cos 15° = 136.7 N，Fy = 141.5 sin 15° = 36.6 N
(2) F 與 x' 夾 45°：Fx' = 141.5 cos 45° = 100 N，Fy' = 141.5 sin 45° = 100 N

(3) x' 與 y 不垂直，要用平行四邊形加正弦定律。力三角形的三個角：F 對面為 60°、Fx' 對面為 75°、Fy 對面為 45°。

Fx' / sin 75° = Fy / sin 45° = 141.5 / sin 60°
Fx' = 157.8 N，Fy = 115.5 N

這裡分力 157.8 N 比合力 141.5 N 還大，正是「斜軸分解時分力可大於合力」的例子。

計算 8

兩力夾角 60°，合力 R = 10√3 N，已知 F1 = 10 N，求 F2。

解答
R² = F1² + F2² + 2F1F2 cos 60°
300 = 100 + F2² + 10F2 → F2² + 10F2 − 200 = 0
(F2 − 10)(F2 + 20) = 0 → F2 = 10 N（負根不合）
計算 9

外伸梁 AB 段受 0 → 8000 N/m 的三角形負載，B 以外 9 m 受 8000 → 5000 N/m 的梯形負載。以等值合力取代，求其作用位置與 B 點的距離。

解答

拆成三塊：AB 段三角形、外伸段 5000 N/m 矩形、外伸段 3000 N/m 三角形（大端在 B）。

F1 = ½ × 4 × 8000 = 16000 N，在 B 左方 4/3 m
F2 = 9 × 5000 = 45000 N，在 B 右方 4.5 m
F3 = ½ × 9 × 3000 = 13500 N，在 B 右方 9/3 = 3 m
R = 74500 N（↓）
74500 x = −16000 × 4/3 + 45000 × 4.5 + 13500 × 3 = 221667 → x = 2.975 m

合力 74.5 kN 作用在 B 點右方 2.975 m 處。

選擇選擇題自測

先自己作答，再點題目看答案與說明

01一鋼製盒子重量 420 lb，等於多少 N？91 年土木普考
  1. (A)1868.2
  2. (B)925.9
  3. (C)190.5
  4. (D)94.4

答案 (A)　1 lbf = 4.448 N，420 × 4.448 ≈ 1868 N。

02下列何者不屬於向量？
  1. (A)加速度
  2. (B)角位移
  3. (C)溫度
  4. (D)力

答案 (C)　溫度只有大小，是純量。

03產生運動效應（外效應）之力，可視為：
  1. (A)自由向量
  2. (B)滑動向量
  3. (C)純量
  4. (D)拘束向量

答案 (B)　剛體的外效應只與作用線有關，力可沿作用線滑動。

04產生變形效應（內效應）之力，屬於：
  1. (A)自由向量
  2. (B)滑動向量
  3. (C)拘束向量
  4. (D)以上皆非

答案 (C)　作用點一移動，構件內部受力情形就改變，所以作用點被「拘束」。

05對於剛體之描述，何者不正確？93 年土木普考
  1. (A)受力時任意兩質點間無相對位移
  2. (B)受力時內部不產生應變能
  3. (C)受力時內部之應變不為零
  4. (D)受力時可以移動或轉動

答案 (C)　剛體不變形，應變恆為零。

06欲求一力對於一點的力矩，可利用：93 年土木普考
  1. (A)位置向量對力向量的外積
  2. (B)力向量對位置向量的內積
  3. (C)力向量對 x 軸的外積
  4. (D)力矩向量對 x 軸的投影

答案 (A)　M = r × F，順序不能顛倒，F × r 方向相反。

07三向量所圍成的平行六面體體積，可用何者計算？93 年土木普考
  1. (A)三向量的內積
  2. (B)三向量絕對值總和
  3. (C)對座標軸投影總和
  4. (D)純量三乘積

答案 (D)　體積 = A ·（B × C）。

08研究物體受力後所產生內效應及變形關係的科學稱為：
  1. (A)靜力學
  2. (B)動力學
  3. (C)運動學
  4. (D)材料力學

答案 (D)　內效應與變形是材料力學的範圍。

09力學的四個基本量不包括：92 年土木普考
  1. (A)時間
  2. (B)力
  3. (C)速度
  4. (D)質量

答案 (C)　四個基本量為時間、空間、質量、力；速度由長度與時間導出。

10剛體的定義是：
  1. (A)應力與應變成比例的物體
  2. (B)受力可變形但不破壞者
  3. (C)體內兩點間的距離永不改變之物體
  4. (D)鋼質的物體

答案 (C)　剛體是理想化模型，實際上不存在。

11使質量 1 kg 的物體產生 1 m/s² 加速度所需的力為：
  1. (A)1 達因
  2. (B)1 耳格
  3. (C)1 牛頓
  4. (D)1 焦耳

答案 (C)　F = ma = 1 kg × 1 m/s² = 1 N。

12兩共點力夾角 120°，大小同為 40 kgf，合力大小為：
  1. (A)40 kgf
  2. (B)20√3 kgf
  3. (C)40√3 kgf
  4. (D)20 kgf

答案 (A)　R² = 40² + 40² + 2·40·40·cos120° = 1600，R = 40 kgf。等大兩力夾 120°，合力與分力等大。

13某物體重 100 kgf，當地 g = 980 cm/s²，以 SI 制表示重量為：
  1. (A)100 N
  2. (B)98 N
  3. (C)98000 N
  4. (D)980 N

答案 (D)　100 kg × 9.8 m/s² = 980 N。

14下列何者正確？
  1. (A)功率為向量
  2. (B)功與能量的單位為瓦特
  3. (C)動能為向量，位能為純量
  4. (D)1 kW = 1000 N·m/s

答案 (D)　功、能、功率都是純量；功的單位 J，功率的單位 W = J/s = N·m/s。

15下列敘述何者為非？
  1. (A)力偶對任意點的力矩為常數
  2. (B)力矩等於力乘以力臂
  3. (C)力、速度、質量都是向量
  4. (D)力的三要素為大小、方向、作用點

答案 (C)　質量是純量。

16關於力的可傳性，何者錯誤？
  1. (A)適用於剛體
  2. (B)力的大小、方向不變
  3. (C)沿作用線移動著力點
  4. (D)可移至平行直線上

答案 (D)　移到平行線上會多出一個力偶，必須補上 C = F·d 才等效（見 1-5）。

17有關力偶的敘述，何者錯誤？
  1. (A)大小相等、方向相反、不共線的兩平行力
  2. (B)三要素為大小、轉向、作用面方位
  3. (C)力偶矩單位與力矩相同
  4. (D)力偶為一純量

答案 (D)　力偶矩是向量，而且是自由向量。

18有關力矩的敘述，何者錯誤？
  1. (A)與力矩軸平行的力，對該軸力矩為零
  2. (B)與力矩軸相交的力，對該軸力矩為零
  3. (C)力沿作用線移動時，力矩大小會改變
  4. (D)力矩愈大，轉動趨勢愈大

答案 (C)　力沿作用線移動，力臂不變，力矩也不變（力的可傳性）。

19x 方向 30 N、y 方向 40 N 作用於一質點，合力為：99 年台灣菸酒
  1. (A)50 N
  2. (B)70 N
  3. (C)120 N
  4. (D)1200 N

答案 (A)　√(30² + 40²) = 50 N。

20某人質量 60 kg，其重量約為：
  1. (A)588 N
  2. (B)1932 N
  3. (C)240 N
  4. (D)900 N

答案 (A)　W = mg = 60 × 9.8 = 588 N。
