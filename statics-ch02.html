2-1自由體圖

把要分析的物體（整體或其中一部分）從周圍環境隔離出來，凡是被拿掉的接觸物，都換成它施加的力，這樣畫出的圖稱為自由體圖（free body diagram，又稱分離體圖）。平衡方程式列得對不對，九成取決於自由體圖畫得對不對。

一、畫自由體圖的步驟

1. 選對象、畫輪廓

決定要分析哪個物體，把它單獨畫出來，周圍的地面、牆、繩、支承全部拿掉。

2. 標上所有外力

已知力（負載、重量）與未知力（支承反力、繩張力）都要畫，一個也不能漏；內力不畫。

3. 未知力先假設方向

算出正值表示假設正確；負值表示實際方向相反，大小不變。

4. 標尺寸與座標

寫上距離、角度與 x、y 軸，列力矩方程式時才找得到力臂。

已知力、負載未知的支承反力、張力

二、常見支承與其反力

判斷反力的原則只有一個：支承限制了物體往哪個方向移動或轉動，就在那個方向產生反力或反力偶。

平面接觸

光滑平面只能推、不能拉，反力 N 垂直於接觸面，指向物體。

曲面接觸

圓柱、球與光滑面接觸，反力垂直於接觸面，並通過圓心。

點與平面

桿端或稜角頂在光滑面上，反力垂直於「被頂的那個面」，不是垂直於桿。

繩索

張力 T 沿繩的方向，背離物體。繩只能拉，算出負值代表假設錯誤。

滑輪

同一條繩繞過無摩擦滑輪，兩側張力相等；滑輪軸承受兩段張力的向量和。

鉸支承與滾支承

鉸支承方向未知，假設成互相垂直的兩分力 Ax、Ay；滾支承只有垂直於支承面的一個反力。

固定支承

限制移動也限制轉動：一個水平反力、一個垂直反力，再加一個反力偶矩 M。

滑塊

滑塊受地面（或導槽）的正向力 N，以及鉸接點傳來的 Ax、Ay。

二力構件

只在兩端受力、中間不受力的構件，兩力必共線、等值、反向，方向就是兩端連線（彎桿也一樣）。

未知數怎麼數？滾支承 1 個、鉸支承 2 個、固定支承 3 個。平面剛體只有 3 條獨立平衡方程式，所以「一鉸一滾」或「一個固定端」剛好可以解出，稱為靜定；未知數超過 3 個就是靜不定，須借助材料力學的變形條件。
最常見的錯誤：把作用力與反作用力畫在同一張自由體圖上。牆推梯子的力畫在梯子上，梯子推牆的力屬於牆，不畫。另外，繩只能受拉，滑輪兩側張力相等的前提是「無摩擦、同一條繩」。

2-2平面力系的合成與平衡

一個質點或剛體同時受兩個以上的力作用，這組力稱為力系（force system）。依各力作用線的關係分類，分類決定了能列幾條獨立的平衡方程式，也就是最多能解幾個未知數。

一、力系的種類

力系特徵平衡方程式獨立方程式數
共線力系各力在同一作用線上ΣF = 01
共面共點力系同一平面，作用線交於一點ΣFx = 0、ΣFy = 02
共面平行力系同一平面，作用線互相平行ΣFy = 0、ΣMA = 02
共面一般力系同一平面，不共點也不平行ΣFx = 0、ΣFy = 0、ΣMA = 03
空間共點力系不在同一平面，作用線交於一點ΣFx = ΣFy = ΣFz = 03
空間平行力系不在同一平面，作用線互相平行ΣFy = 0、ΣMx = 0、ΣMz = 03
空間一般力系不共點、不平行、不共面三個力方程式＋三個力矩方程式6

二、平面共點力系的平衡

各力交於一點 O，對 O 的力矩自然為零，只剩兩條力的方程式：

平衡條件
R = 0　⇔　ΣFx = 0，ΣFy = 0
圖解法：各力首尾相接的力多邊形封閉，合力即為零。

二力平衡

兩力大小相等、方向相反，而且作用在同一直線上（只等值反向而不共線，會形成力偶）。

三力平衡

三個不平行的共面力平衡時，三力的作用線必交於一點；若三力平行，則合力為零且合力矩為零。

三力共點這條性質很好用：知道兩力的作用線，就能直接定出第三力（例如鉸支承反力）的方向，不必先拆成兩個分力。

三、拉密定理

拉密定理（Lami's theorem）
F1 / sin θ1 = F2 / sin θ2 = F3 / sin θ3
只適用於三個共點力平衡；θ 是每個力「對面」兩力之間的夾角，三角相加為 360°。

力三角形法：三力平衡時首尾相接成封閉三角形，三角形的邊長比就是力的比。上圖為 30°–60°–90° 三角形，故 F1 : F2 : F3 = 1 : 2 : √3。遇到 3-4-5、30°-60°-90°、45° 這類特殊角，用幾何比例往往比列方程式更快。

四、剛體的平衡方程式

剛體平衡須同時滿足「不移動」與「不轉動」：合力為零、對任一點的合力矩也為零。平面一般力系有三種等價的寫法，各有使用限制：

形式方程式限制條件
基本形式ΣFx = 0、ΣFy = 0、ΣMA = 0A 為平面上任一點；x、y 兩方向不可平行
二力矩形式ΣFx = 0、ΣMA = 0、ΣMB = 0A、B 連線不可與 x 軸垂直
三力矩形式ΣMA = 0、ΣMB = 0、ΣMC = 0A、B、C 三點不可共線
為什麼有限制？若 ΣMA = ΣMB = 0，力系仍可能剩下一個通過 A、B 連線的合力。再加一條「不垂直於 AB 的方向」的力平衡，或對 AB 線外的第三點取力矩，才能排除這個合力。
解題順序：先對「兩個未知力的交點」取力矩，一條方程式就解出第三個未知數，避免聯立。例如簡支梁先對 A 取力矩求 NB，再用 ΣF 求 Ax、Ay。

2-3空間力系的平衡

一、空間力的分量

空間問題採用右手座標系（right-handed coordinate system）：右手四指由 +x 軸彎向 +y 軸，大拇指所指即為 +z 軸。一力可分解為三個互相垂直的分量：

直角分量
F = Fx i + Fy j + Fz k
F = √(Fx² + Fy² + Fz²)　　cos θx = Fx/F，cos θy = Fy/F，cos θz = Fz/F

θx、θy、θz 是力與三個座標軸的夾角，其餘弦稱為方向餘弦，滿足 cos²θx + cos²θy + cos²θz = 1。

二、用單位向量求分量

題目通常給「力的大小」和「作用線經過的兩點」。先求兩點連線的單位向量，再乘上大小：

單位向量法
F = F · r / |r|
r 為沿作用線的位置向量（終點座標減起點座標），方向要與力的指向一致。

以上圖為例，r = (3, 4, 2)，|r| = √(9 + 16 + 4) = √29 = 5.385：

Fx = 100 × 3/5.385 = 55.7 N，Fy = 100 × 4/5.385 = 74.3 N，Fz = 100 × 2/5.385 = 37.1 N
F = 55.7 i + 74.3 j + 37.1 k　N

三、空間力系的平衡條件

空間共點力系
ΣFx = 0
ΣFy = 0
ΣFz = 0
空間一般力系
ΣFx = ΣFy = ΣFz = 0
ΣMx = ΣMy = ΣMz = 0
最多解 6 個未知數

四、力矩的向量計算

力對一點的力矩：由 O 點到力作用線上任一點的位置向量為 r = x i + y j + z k，則

力對點的力矩
MO = r × F
= (yFz − zFy) i + (zFx − xFz) j + (xFy − yFx) k

外積順序不可顛倒：F × r = −r × F，方向會整個相反。用行列式記最不容易錯：第一列 i、j、k，第二列 x、y、z，第三列 Fx、Fy、Fz。

力對一軸的力矩：先求對軸上任一點 O 的力矩，再投影到軸的單位向量 ea 上：

力對軸的力矩
Ma = (r × F) · ea
結果是純量（純量三重積）；若要向量形式，再乘上 ea。力與軸平行或相交時，對該軸的力矩為零。

範例 196 年台電

500 kg 的質量塊以不可伸長的細繩懸吊如圖，AC 與天花板夾 30°，BC 與天花板夾 60°。求靜平衡時兩繩的張力 TAC 與 TBC。

解答

取 C 節點的自由體圖，三力共點：

ΣFx = 0：TAC cos 30° = TBC cos 60°
ΣFy = 0：TAC sin 30° + TBC sin 60° = 500
解得 TAC = 250 kgf（≈ 2453 N），TBC = 433 kgf（≈ 4248 N）

另解：兩繩夾 90°，力三角形為 30°-60°-90°，TAC = 500 sin 30° = 250，TBC = 500 cos 30° = 433。

範例 2108 年台電

重物 W 由細繩 AB 與細繩 BCD 懸掛，BCD 繞過無摩擦滑輪 C，D 端吊 200 kN。AB 與鉛垂線夾 45°，BC 與鉛垂線夾 30°。W 最接近：(A) 231　(B) 273　(C) 315　(D) 357 kN

解答

繩繞過無摩擦滑輪，張力不變，TBC = 200 kN。B 點三力共點，用拉密定理：

W 的對角：TAB 與 TBC 的夾角 = 45° + 30° = 75°
TBC 的對角：W 與 TAB 的夾角 = 180° − 45° = 135°
200 / sin 135° = W / sin 75°　→　W = 200 × 0.9659 / 0.7071 = 273.2 kN，選 (B)
範例 393 年機械高考

滑塊 A 套在與水平成 45° 的光滑桿上，以繩經滑輪吊 200 N 的重物，繩與鉛垂線夾 20°，系統平衡。求滑塊 A 的質量。

解答

取滑塊 A 的自由體圖：重量 W 向下、繩拉力 200 N（偏右 20°）、桿的正向力 N（垂直於桿）。桿光滑，只要「沿桿方向」的分力平衡即可，N 不會出現：

沿桿方向：W sin 45° = 200 sin(45° − 20°) = 200 sin 25°
W = 200 × 0.4226 / 0.7071 = 119.5 N
m = W / g = 119.5 / 9.81 = 12.2 kg

若要求 N，取垂直桿的方向：N = 200 cos 25° − W cos 45° = 181.3 − 84.5 = 96.7 N。

原講義以 ΣFx、ΣFy 聯立，得到 N = −96.73 N，負號只代表 N 的實際方向與假設相反。沿桿、垂直桿取座標軸，可以一條方程式解一個未知數。

範例 4108 年台電

重 W = 600 N 的球置於光滑的鉛直牆與斜率 7：24 的光滑斜面之間。斜面在 B 點的反力最接近：(A) 625　(B) 675　(C) 1250　(D) 2124 N

解答

球受三力：W 向下、牆的反力 NA（水平）、斜面反力 NB（垂直斜面）。斜面斜率 7：24，斜邊 25，NB 的鉛直分量占 24/25：

ΣFy = 0：NB × 24/25 = 600　→　NB = 625 N，選 (A)
ΣFx = 0：NA = NB × 7/25 = 175 N
範例 596 年台電

彈簧 K1 = 10000 N/m、K2 = 30000 N/m 並聯拉住物體，W = 600 N，α = 30°，接觸面光滑。K1 受力為：(A) 75　(B) 100　(C) 150　(D) 200 N

解答

沿斜面方向平衡，兩彈簧並聯、伸長量相同：

F1 + F2 = W sin 30° = 300 N
(k1 + k2) δ = 300　→　δ = 300 / 40000 = 0.0075 m
F1 = k1 δ = 10000 × 0.0075 = 75 N，選 (A)

並聯彈簧依勁度比例分擔負載：K1 占 1/4。

範例 6108 年台電

重 360 N 的圓柱以軟繩懸掛，並靠在與水平成 30° 的光滑斜面上，繩與天花板夾 60°。斜面的反力為：(A) 120√3　(B) 180√3　(C) 240√3　(D) 360√3 N

解答

三力共點於圓心 O：W 向下；繩張力 T 指向左上，與水平夾 60°；斜面反力 N 垂直斜面，指向右上，與水平夾 60°。

N 與 T 夾 60°（W 的對角），W 與 T 夾 150°（N 的對角）
360 / sin 60° = N / sin 150°　→　N = 360 × 0.5 / 0.866 = 120√3 N，選 (A)

T 與 N 對稱於鉛垂線，兩者相等，T 也是 120√3 N。

範例 797 年台電

圖示滑輪組，忽略滑輪重量與摩擦，θ = 30°。欲維持系統靜止，張力 T 為：(A) W/4　(B) W/2　(C) W　(D) √3W/4

解答

同一條繩張力處處相等，與拉出的角度 θ 無關。由上往下逐一取自由體圖：

上方動滑輪：繩 1 兩段向上共 2T，故下方軸鉤的繩 2 張力為 2T
下方動滑輪：繩 2 兩段向上共 4T，與 W 平衡
4T = W　→　T = W/4，選 (A)
範例 897 年台電

質量 m 的工人坐在吊椅上，自己下拉繩子以支撐自己，滑輪與繩重不計。所需拉力 P 為多少 m × 9.8 N？(A) 1/5　(B) 1/4　(C) 1/3　(D) 1/2

解答

工人拉的繩張力為 P，繞過動滑輪 B 後兩段共 2P 向上拉 B，所以連接 B 軸與滑輪 A 的繩張力為 2P。

取「人＋吊椅＋滑輪 A」為自由體：A 的兩段繩向上 2P × 2 = 4P，人手上的繩向上拉人 P
4P + P = mg　→　P = mg/5，選 (A)

人拉繩向下，繩也拉人向上，這個 P 必須算進「人＋吊椅」的自由體，最容易漏掉。

範例 993 年機械高考

重 W、長 L 的均勻桿靠在台階邊角，下端 A 以水平繩拉住，所有接觸面光滑，台階高 L/2，A 到台階的水平距離 L/2。水平繩的張力為何？

解答

桿與水平夾 45°，A 到邊角沿桿的距離為 (L/2)/cos 45°。邊角的反力 N2 垂直於桿，地面反力 N1 向上，繩拉力 T 水平：

ΣMA = 0：N2 × (L/2)/cos 45° = W × (L/2) cos 45°　→　N2 = W cos²45° = 0.5W
ΣFx = 0：T = N2 sin 45° = 0.354W
ΣFy = 0：N1 = W − N2 cos 45° = 0.646W
範例 1098 年機械特考四等

凹槽底寬 45 cm，大圓柱 40 kg、直徑 36 cm；小圓柱 10 kg、直徑 24 cm，接觸面均光滑。求 (1) 小圓柱在 A、B 處的受力；(2) 大圓柱在 C、D 處的受力。

解答

先求兩圓心連線與水平的夾角 θ：水平距 45 − 18 − 12 = 15 cm，圓心距 18 + 12 = 30 cm。

cos θ = 15 / 30　→　θ = 60°

(1) 取小圓柱：B 處反力沿圓心連線，A 處反力水平。

ΣFy = 0：NB sin 60° = 10　→　NB = 11.55 kgf
ΣFx = 0：NA = NB cos 60° = 5.77 kgf

(2) 取兩圓柱整體：

ΣFy = 0：NC = 40 + 10 = 50 kgf；ΣFx = 0：ND = NA = 5.77 kgf
範例 1198 年普考機械設計

引擎的活塞、連桿 AB 與曲柄 BC 如圖，P = 4 kN。求維持平衡所需的扭矩 T，以及連桿 AB 的軸向力 FAB。（圖未依比例）

解答

連桿 AB 是二力構件，力沿 AB 方向。設活塞導槽的鉛直反力為 P2，取活塞：AB 力的水平分量 = 4 kN，鉛直分量 = P2。

AB 斜率 6/20，故 P2 = 4 × 6/20 = 1.2 kN
取整體對 C 取力矩（P 的作用線通過 C）：T = P2 × 28 = 33.6 kN·cm
FAB = √(4² + 1.2²) = 4.18 kN（壓力）

講義另取 BC 自由體：4 × 6 + P2 × 8 = T，與上式聯立得相同結果。

範例 1294 年土木普考

力 P = (25 i + 36 j + 12 k) kgf 作用於 C(2.5, 3.7, 1.8) m，此力對 x 軸的力矩為：(A) −20.4 i　(B) 20.4 i　(C) −17.2 i　(D) 17.2 i　kgf·m

解答
Mx = yPz − zPy = 3.7 × 12 − 1.8 × 36 = 44.4 − 64.8 = −20.4
故 Mx = −20.4 i kgf·m，選 (A)

原講義算成 P × r，得 +20.4 而選 (B)，順序顛倒了。力矩一律是 r × F；同一題在選擇題第 67 題，該處答案正確標為 (A)。

範例 1398 年台電

平面上一力 p = 5 i + 8 j 作用於 A 點，A 點座標為 (−5, 10)。此力對原點的力矩為：(A) 55 k　(B) −55 k　(C) 90 k　(D) −90 k

解答
MO = r × p = (−5 i + 10 j) × (5 i + 8 j)
= [(−5)(8) − (10)(5)] k = (−40 − 50) k = −90 k，選 (D)

平面問題只有 k 分量：M = xFy − yFx，負號代表順時針。

範例 1494 年土木普考

長 3.4 m 的繩 AO，作用於 A 點的拉力 F = (−120 i − 90 j − 80 k) N，O 為原點。A 點的 z 座標為何？

解答
|F| = √(120² + 90² + 80²) = 170 N
繩力由 A 指向 O，單位向量為 (−120, −90, −80)/170
A 點位置 = −3.4 × (−120, −90, −80)/170 = (2.4, 1.8, 1.6) m，故 z = 1.6 m
範例 15106 年台電

重 200 N、直徑 1 m 的圓柱，受高度 0.75 m 的水平力 F 作用，準備滾上 0.25 m 的台階。剛好離開地面時 F 為：(A) 173.2　(B) 233.6　(C) 266.3　(D) 333.3 N

解答

剛要滾上台階時，地面反力 = 0，圓柱只受 F、W 與台階邊角 B 的反力。對 B 取力矩，B 的反力消去：

F 的力臂 = 0.75 − 0.25 = 0.5 m；W 的力臂 = √(0.5² − 0.25²) = 0.433 m
F × 0.5 = 200 × 0.433　→　F = 173.2 N，選 (A)
範例 16100 年台電

01平面剛體力系已用了 ΣMA = 0 與 ΣMB = 0，關於第三條方程式，何者有誤？93 年土木普考
  1. (A)可對第三點 C 取 ΣMC = 0，只要 A、B、C 不共線

02一物體處於平衡狀態，是指該物體：
  1. (A)靜止不動
  2. (B)作等速度直線運動
  3. (C)作等速圓周運動
  4. (D)作直線等加速度運動

答案 (A)　本題答案取 (A)。嚴格來說等速直線運動也是平衡（合力為零），但靜力學討論的是靜止平衡；等速圓周運動有向心加速度，不是平衡。

  1. (A)一個未知力
  2. (B)兩個未知力
  3. (C)三個未知力
  4. (D)四個未知力

答案 (C)　共面一般力系有 ΣFx、ΣFy、ΣM 三條獨立方程式。

04物體受同平面三力作用而保持平衡時，其作用線：

  2. (B)相交於兩點
  3. (C)相交於一點
  4. (D)互相垂直

答案 (C)　三力平衡定理：不平行的三力必共點。

05若一力系的平衡以 ΣFy = 0、ΣMA = 0 即可描述，此力系為：

  2. (B)同平面一般力系
  3. (C)同平面平行力系
  4. (D)空間共點力系

答案 (C)　各力都平行於 y 軸，ΣFx 自動為零，只剩兩條。

06二同向平行力 P 與 Q，P > Q，其合力位置：

  4. (D)在 P、Q 之外，靠近 Q

答案 (A)　同向平行力的合力在兩力之間，到兩力的距離與力的大小成反比，所以靠近大力 P。
